# Riya Dhunna — Portfolio

Premium, recruiter-focused developer portfolio built with **React + Vite + Tailwind CSS + Framer Motion**.

## ✨ Features

- Dark/light theme toggle, glassmorphism UI, gradient accents
- Hero with typing animation & floating avatar
- Animated counters for achievements
- Interactive timeline of milestones
- Smooth scroll, sticky navbar, scroll progress bar
- Custom cursor glow & subtle hover effects
- Fully responsive (mobile-first)

## 🚀 Getting Started

```
npm install
npm start
```

Open http://localhost:3000

## 🏗️ Build

```
npm run build
npm run preview
```

## 📁 Structure

```
src/
├── components/      # All UI sections
├── data.js          # Single source of truth (edit me!)
├── App.jsx          # Layout & routing of sections
├── main.jsx         # Entry
└── index.css        # Tailwind + theme
```

## ✏️ Customize

Edit `src/data.js` to update profile, projects, skills, achievements, etc.
Your `resume.pdf` is already in the `public/` folder so the Resume button works.

## 🌐 Deploy

The easiest way to go live is [Vercel](https://vercel.com):

1. Push this project to a new GitHub repo (e.g. `RiyaDhunna2004/Portfolio`)
2. Go to vercel.com → New Project → import that repo
3. Framework preset: Vite (auto-detected) → Deploy

That's it — you'll get a live URL just like the one this template was based on.
